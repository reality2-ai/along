Install Along and use it offline

Course exercise — use at your own risk. Along was created as an exercise for an AI-assisted coding course. It is an experimental educational webapp, not an official Auckland Transport service. Routes, times, walking directions and accessibility information may be incomplete, outdated or incorrect. Check your journey and access requirements with AT before travelling.

Along runs on your device. The portal delivers the app and updates; it does not run your journey searches. Once the app and travel data are downloaded, the core app works even when you have no connection or the portal is unavailable.

Your journey searches, saved routes, learned routines and preferences stay in this browser on this device. No account, analytics service, uploaded journey history or background tracking is required. Along does not currently sync devices.

Scheduled information, not live tracking

The public Along app uses downloaded timetables. It does not show live bus, train or ferry positions, current delays or cancellations. Being online does not turn its journey plans or stop departure boards into live information. Displayed departures are scheduled times; walking and transfer times are estimates. A saved journey does not reserve a service or guarantee a connection.

For live departure information and vehicle tracking, use AT Mobile or check the AT website before travelling. These links need an internet connection and open AT's services. Check the timetable date and current service/access conditions before relying on a journey.

Prepare once, then check the installed app

  1. Open the hosted Along app over HTTPS in a normal browser window, not private browsing or an in-app social-media browser. Open https://reality2.ai/along/.
  2. Keep it open while the first download completes (about 40 MB, with more space needed after decompression). Open Settings and wait for offline ready.
  3. Follow your platform's installation steps below.
  4. Open the installed Along icon while still online. Check Settings again and let any download finish. Some platforms use separate storage for installed apps.
  5. Turn off Wi-Fi/mobile data, close and reopen Along from its icon, and try a new address search and journey. Check a route map too. Reconnect afterwards.

An icon alone does not prove offline readiness. If the offline check fails, reopen online in the installed app and finish preparation before relying on it.

Chrome — Windows, Linux, macOS and Chromebook
  1. Open Along in Chrome and finish preparation.
  2. Select the install icon in the address bar, or ⋮ → Cast, save and share → Install page as app. Confirm the installation.
  3. Open Along from Start on Windows, your application launcher on Linux, your app launcher/Spotlight on macOS, or the Chromebook Launcher. You can also find installed apps at chrome://apps.
  4. Pin the app to your taskbar, Dock or shelf using your operating system's menu.

Google's desktop instructions.

Edge — Windows, Linux and macOS
  1. Open Along in Edge and finish preparation.
  2. Select the install icon, or … → More tools → Apps → Install this site as an app. Some versions put Apps directly in the menu. Confirm.
  3. Open edge://apps to find Along. On Windows, its Details page offers Start, taskbar and desktop shortcuts. On Linux/macOS, use the system's application launcher and pin the running app if wanted; the available shortcuts vary.

Microsoft's installation and app-management instructions.

Brave — Windows, Linux and macOS
  1. Open Along in Brave and finish preparation.
  2. Select the install icon if shown, or use the main menu's Save and Share → Install page as app. Some versions use Cast, save and share. Confirm.
  3. Open Along from your operating system's application launcher, then pin it there if wanted. Keep Brave and the profile used for installation available.

Brave's support-team explanation describes the desktop menu. Along's Install Along button in Settings is another entry point when the browser offers it. If no installation action is available, use a current supported browser; creating a bookmark alone does not prove offline preparation. Brave-specific physical validation is pending.

Safari — macOS

On macOS Sonoma 14 or later, open Along in Safari, then choose File → Add to Dock (also available through Share). Name it Along, choose Add, and open the new app from the Dock or Spotlight. Check offline readiness inside that app while still online; it can have separate storage from Safari. On older macOS versions, use a maintained Chrome, Edge or Brave version with web-app installation. Apple's Mac instructions.

Chrome — Android phone or tablet

Open Along, finish preparation, then tap ⋮ → Install and create shortcut → Install. Depending on the version, the menu may instead show Install app or Add to Home screen. Confirm and open the new Along icon from the home screen or app launcher. Settings → Install Along may also be available. Google's Android instructions.

Edge or Brave — Android phone or tablet

Open Along and finish preparation. First try Install Along in the app's Settings, if shown. Otherwise open the browser menu and look for Install app, Add to Home screen, or Add to phone. Choose the available action and confirm placement of the icon. Open that icon online, then repeat the offline check.

The label and whether you get a standalone app or a home-screen shortcut depend on the browser/version. We have not verified every mobile menu. If no installation action is offered, open the same Along URL in Chrome and use its documented path; that browser/profile will need its own download. Do not confuse adding a favourite with preparing an offline app. Brave's Android project tracks home-screen installation UI; Microsoft's mobile help covers Edge's mobile browser, whose menus differ from desktop.

Safari — iPhone and iPad

Open Along in Safari, then choose Share → Add to Home Screen. Use View More or Edit Actions if needed. Enable Open as Web App if offered, then tap Add. Open the new icon while online and wait for offline readiness inside it. Physical iOS/iPadOS validation of Along is pending. Apple's iPhone instructions, Apple's iPad instructions.

Chrome — iPhone and iPad

Open Along in Chrome. Use Share → Add to Home Screen, confirm the name and tap Add. Open the icon online before testing offline. If the option is absent, open the address in Safari and follow the Safari steps. Google notes that a home-screen item can open either a web app or the default browser depending on availability: check the actual result rather than assuming the icon is sufficient. Google's iPhone/iPad instructions.

Edge or Brave — iPhone and iPad

Open the browser's Share action and use Add to Home Screen if offered. If it is missing, copy the Along address into Safari and use Share → Add to Home Screen there. Do not use desktop instructions such as Install page as app on iOS. Brave's support team documented iOS limitations separately from its desktop support; this guide does not assume a later mobile version has the same menu. Finish preparation in the installed icon and perform the offline check. Brave's support response, Apple's installation path.

If installation is unavailable

You can use Along in a supported browser tab and bookmark its HTTPS address. Offline use still depends on successful app/data caching in that browser profile. A saved HTML page, screenshot, ordinary shortcut or unpacked file:// ZIP is not an offline installation. Browser menus change; follow the official instructions for the browser/version you use. The platform list describes installation paths, not a claim that every platform has been physically tested.

The installed app uses your browser's runtime and local storage. Keep that browser installed. Clearing site data, changing browser/profile, removing the app or device storage cleanup can remove its data. The timetable has an expiry date in Settings; offline does not mean schedules remain accurate forever. Open online periodically and use Update downloaded timetable and Check for an app update.

Your data stays here

Addresses you type and journey searches are processed locally, including when online. Saved routes and routine learning are stored locally. Forget my journey history in Settings clears learned/saved journeys; disabling suggestions stops learning. Clearing this app's site data also removes offline downloads. Use your device's screen lock to protect locally stored information.

Ordinary website/data downloads still send connection information, such as your IP address, to the host. Optional online street maps send visible map-area requests to OpenStreetMap. A configured live backend receives feed requests. Along does not send your typed addresses, saved journeys or routine history with those requests. Device/OS backup and browser policies remain outside Along's control.

Different browsers, profiles and site origins have separate storage. Installing from a new public URL will not migrate data from a private/test site. There is no cloud account or automatic cloud backup of your journeys in Along.
