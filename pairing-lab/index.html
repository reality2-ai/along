Experimental course exercise — use at your own risk. This page tests device pairing and local AT-key storage. It does not sync journeys or contact AT. For this lab, use dummy key text such as along-test-key; do not enter a real AT key.

Keys are encrypted in browser software, without hardware-backed protection. Code running on this site can use them. Clearing browser data can lose access.

Use the same Wi-Fi network if possible. Direct connections across different networks may fail. Keep both devices open; invitations expire after one minute.
